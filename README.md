# Studio Indigoblue

The website of Studio Indigoblue, Simon Kim's one-person studio, at https://studioindigoblue.com: a blog built from scratch to learn full-stack development. The repository keeps its original name, Devel.

- `devel-frontend/`: React + TypeScript SPA (Vite, Tailwind)
- `blog-engine/`: Go API (standard library `net/http`)
- `infra/`: Azure infrastructure (Bicep) and pipeline docs

Start with [docs/LEARNING.md](docs/LEARNING.md) to see where each kind of change lives.
